# Прокат 212

Публичная витрина на GitHub Pages. HTML, стили, фотографии и начальный каталог находятся в этом репозитории. Сервер обновляет данные каталога при доступном соединении, принимает заявки и предоставляет админ-панель.

При недоступности фонового обновления витрина и корзина используют сохранённый каталог. При подтверждении заявки сервер проверяет актуальность выбранных позиций.
